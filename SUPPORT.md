# Support Channels

Welcome to the **EricksonLopez.Auditing** support guide. If you need help with installation, architecture design, database adapter configuration, or troubleshooting, please review the resources below.

* 📚 [**Public API Reference**](docs/api-reference.md) — Full API specification for all 12 ecosystem packages.

## 2. GitHub Issues

Use [GitHub Issues](https://github.com/ericksonlopezf/dotnet-auditing/issues) for:

* **Bug Reports:** If you discover a defect or unexpected behavior in the codebase. Please use the [Bug Report Template](.github/ISSUE_TEMPLATE/bug_report.md) with a minimal reproducible example.
* **Feature Requests:** If you want to propose an API improvement or support for an additional database driver. Please use the [Feature Request Template](.github/ISSUE_TEMPLATE/feature_request.md).

---

## 3. Security Reports

For confidential vulnerability disclosures, please do **not** open a public issue. Follow our [Security Policy](SECURITY.md) and email [ericksonlopezf@gmail.com](mailto:ericksonlopezf@gmail.com).
