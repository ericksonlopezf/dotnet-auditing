# ELM009: Stream Handler Not Found

| Property | Value |
|---|---|
| **Rule ID** | `ELM009` |
| **Category** | `EricksonLopez.Mediator.Design` |
| **Severity** | `Error` |
| **Enabled by Default** | `true` |
| **Applies to** | Types implementing `IStreamQuery<TResponse>` |

---

## 🎯 Rule Description

Emitted when an asynchronous streaming query implementing `IStreamQuery<TResponse>` has no corresponding `IStreamQueryHandler<TQuery, TResponse>` registered in the compilation.

---

## ❌ Violation Example

```csharp
public readonly record struct StreamTelemetryQuery(DateTime From, DateTime To) : IStreamQuery<MetricPoint>;

// Violation: No stream handler found for StreamTelemetryQuery
```

---

## ✅ Compliant Example

```csharp
public sealed class StreamTelemetryHandler : IStreamQueryHandler<StreamTelemetryQuery, MetricPoint>
{
    public async IAsyncEnumerable<MetricPoint> Handle(StreamTelemetryQuery query, [EnumeratorCancellation] CancellationToken ct)
    {
        yield return new MetricPoint(DateTime.UtcNow, 42.0);
    }
}
```
