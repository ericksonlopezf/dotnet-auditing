# ELM006: Notification Handler Not Found

| Property | Value |
|---|---|
| **Rule ID** | `ELM006` |
| **Category** | `EricksonLopez.Mediator.Design` |
| **Severity** | `Warning` |
| **Enabled by Default** | `true` |
| **Applies to** | Types implementing `INotification` |

---

## 🎯 Rule Description

Emitted when a notification type is defined in the compilation, but zero `INotificationHandler<TNotification>` implementations are registered. While notifications are fire-and-forget publish-subscribe messages where zero subscribers is syntactically legal, `ELM006` warns developers that publishing the notification will execute as a no-op.

---

## ❌ Violation Example

```csharp
public readonly record struct OrderPaidEvent(Guid OrderId) : INotification;

// Warning: No handler found for notification OrderPaidEvent. It will be ignored when published.
```

---

## ✅ Compliant Example

```csharp
public sealed class OrderPaidEventHandler : INotificationHandler<OrderPaidEvent>
{
    public ValueTask Handle(OrderPaidEvent notification, CancellationToken cancellationToken)
    {
        // Execute side effect (e.g., send confirmation email)
        return ValueTask.CompletedTask;
    }
}
```
