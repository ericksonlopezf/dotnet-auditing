# ELM004: Invalid Handler Signature

| Property | Value |
|---|---|
| **Rule ID** | `ELM004` |
| **Category** | `EricksonLopez.Mediator.Design` |
| **Severity** | `Error` |
| **Enabled by Default** | `true` |
| **Applies to** | Classes implementing `ICommandHandler`, `IQueryHandler`, `INotificationHandler`, or `IPipelineBehavior` |

---

## 🎯 Rule Description

`EricksonLopez.Mediator` standardizes on **`ValueTask<TResponse>`** across all handlers and pipeline continuations to guarantee zero allocations on synchronous completion paths.

If a handler defines a `Handle` method returning `Task<TResponse>`, `void`, or using an incorrect parameter list (missing `CancellationToken`), `ELM004` is raised.

---

## ❌ Violation Example

```csharp
public sealed class BadHandler : ICommandHandler<CreateUserCommand, Result<Guid>>
{
    // Violation: Returns Task<T> instead of ValueTask<T>
    public async Task<Result<Guid>> Handle(CreateUserCommand command, CancellationToken cancellationToken)
    {
        return Result<Guid>.Success(Guid.NewGuid());
    }
}
```

---

## ✅ Compliant Example

```csharp
public sealed class CorrectHandler : ICommandHandler<CreateUserCommand, Result<Guid>>
{
    // Compliant: Returns ValueTask<T> with CancellationToken parameter
    public ValueTask<Result<Guid>> Handle(CreateUserCommand command, CancellationToken cancellationToken)
    {
        return ValueTask.FromResult(Result<Guid>.Success(Guid.NewGuid()));
    }
}
```
