# ELM005: Open Generic Handler Not Supported

| Property | Value |
|---|---|
| **Rule ID** | `ELM005` |
| **Category** | `EricksonLopez.Mediator.Design` |
| **Severity** | `Warning` |
| **Enabled by Default** | `true` |
| **Applies to** | Open-generic handler types |

---

## 🎯 Rule Description

Open-generic handler classes (e.g. `class GenericHandler<T> : ICommandHandler<T, Result>`) cannot be wired up at compile time by the Roslyn source generator because the full set of concrete generic arguments cannot be resolved statically.

`ELM005` informs developers that such handlers are skipped by the generator and will not be wired into the DI container or dispatch table.

---

## ❌ Violation Example

```csharp
// Warning: Open generic handlers are not registered by compile-time source generators
public sealed class GenericAuditHandler<TCommand> : ICommandHandler<TCommand, Result>
    where TCommand : ICommand<Result>
{
    public ValueTask<Result> Handle(TCommand command, CancellationToken ct) => ...;
}
```

---

## ✅ Compliant Example (Use Generic Pipeline Behavior Instead)

```csharp
public sealed class AuditPipelineBehavior<TRequest, TResponse> : IPipelineBehavior<TRequest, TResponse>
    where TRequest : ICommand<TResponse>
{
    public async ValueTask<TResponse> Handle<TNext>(TRequest request, TNext next, CancellationToken ct)
        where TNext : struct, INext<TResponse>
    {
        return await next.InvokeAsync().ConfigureAwait(false);
    }
}
```
