# ELM010: Multiple Stream Handlers Found

| Property | Value |
|---|---|
| **Rule ID** | `ELM010` |
| **Category** | `EricksonLopez.Mediator.Design` |
| **Severity** | `Error` |
| **Enabled by Default** | `true` |
| **Applies to** | Types implementing `IStreamQuery<TResponse>` |

---

## 🎯 Rule Description

Streaming queries must have exactly one handler producing the asynchronous stream sequence. If multiple implementations of `IStreamQueryHandler<TQuery, TResponse>` are discovered, compilation fails with `ELM010`.

---

## ❌ Violation Example

```csharp
public readonly record struct StreamEventsQuery : IStreamQuery<EventItem>;

public sealed class DatabaseStreamHandler : IStreamQueryHandler<StreamEventsQuery, EventItem> { ... }
public sealed class KafkaStreamHandler : IStreamQueryHandler<StreamEventsQuery, EventItem> { ... } // Violation
```

---

## ✅ Compliant Example

Consolidate streaming logic or differentiate query types:

```csharp
public sealed class StreamEventsHandler : IStreamQueryHandler<StreamEventsQuery, EventItem>
{
    public async IAsyncEnumerable<EventItem> Handle(StreamEventsQuery query, [EnumeratorCancellation] CancellationToken ct)
    {
        yield return new EventItem("Sample");
    }
}
```
