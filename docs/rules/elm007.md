# ELM007: Unsupported Open Generic Behavior

| Property | Value |
|---|---|
| **Rule ID** | `ELM007` |
| **Category** | `EricksonLopez.Mediator.Design` |
| **Severity** | `Error` |
| **Enabled by Default** | `true` |
| **Applies to** | Classes implementing `IPipelineBehavior` or `INotificationBehavior` |

---

## 🎯 Rule Description

Pipeline behaviors must define exactly two generic type parameters (`TRequest, TResponse`), while notification behaviors must define exactly one type parameter (`TNotification`). Declaring behaviors with 3 or more generic type parameters cannot be closed by the generator and raises `ELM007`.

---

## ❌ Violation Example

```csharp
// Violation: Behavior has 3 generic type parameters. Only 2 are supported (TRequest, TResponse).
public class InvalidBehavior<TRequest, TResponse, TContext> : IPipelineBehavior<TRequest, TResponse>
{
    ...
}
```

---

## ✅ Compliant Example

```csharp
public class ValidBehavior<TRequest, TResponse> : IPipelineBehavior<TRequest, TResponse>
{
    public async ValueTask<TResponse> Handle<TNext>(TRequest request, TNext next, CancellationToken ct)
        where TNext : struct, INext<TResponse>
    {
        return await next.InvokeAsync().ConfigureAwait(false);
    }
}
```
