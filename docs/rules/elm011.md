# ELM011: Invalid Stream Handler Signature

| Property | Value |
|---|---|
| **Rule ID** | `ELM011` |
| **Category** | `EricksonLopez.Mediator.Design` |
| **Severity** | `Error` |
| **Enabled by Default** | `true` |
| **Applies to** | Types implementing `IStreamQueryHandler` |

---

## 🎯 Rule Description

Stream query handlers must return `IAsyncEnumerable<TResponse>` and accept `(TQuery query, CancellationToken cancellationToken)`. If the signature deviates (e.g. returning `IEnumerable<T>` or `Task<IAsyncEnumerable<T>>`), `ELM011` is emitted.

---

## ❌ Violation Example

```csharp
public sealed class BadStreamHandler : IStreamQueryHandler<FetchLogsQuery, LogEntry>
{
    // Violation: Returns IEnumerable instead of IAsyncEnumerable
    public IEnumerable<LogEntry> Handle(FetchLogsQuery query, CancellationToken ct) => ...;
}
```

---

## ✅ Compliant Example

```csharp
public sealed class CompliantStreamHandler : IStreamQueryHandler<FetchLogsQuery, LogEntry>
{
    public async IAsyncEnumerable<LogEntry> Handle(FetchLogsQuery query, [EnumeratorCancellation] CancellationToken ct)
    {
        yield return new LogEntry("Log 1");
    }
}
```
