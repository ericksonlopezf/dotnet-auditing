# ADR-0010: Stryker Equivalent Mutants & Compiler Exclusions

## Status
**Accepted**

## Date
2026-08-26

## Context
During Stryker.NET mutation testing, certain mutations generated by Stryker mutate infrastructure or compiler constructs that do not reflect observable domain behavior or result in equivalent mutants:
1. Mutating `ConfigureAwait(false)` booleans.
2. Mutating `Dispose()` / `DisposeAsync()` defensive calls in test doubles.
3. Mutating Roslyn-generated state machines for `async Task` methods.

## Decision
1. Explicitly ignore non-behavioral infrastructure methods in `stryker-*.json`:
   ```json
   "ignore-methods": [
     "ConfigureAwait",
     "Dispose"
   ]
   ```
2. Maintain strict `break: 95` and `high: 100` thresholds across all packages.
3. Handle any rare structurally equivalent mutations via targeted inline comments (`// Stryker disable once all : Equivalent mutation`) rather than weakening global configuration thresholds.

## Consequences
### Positive
- Prevents spurious CI failures on non-functional compiler artifacts.
- Ensures 100% meaningful mutant kill rate on all domain logic and cryptographic pipelines.
