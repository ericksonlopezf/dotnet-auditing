# API Reference — EricksonLopez.Mediator

Comprehensive technical reference documentation formatted in Microsoft Learn style for all public contracts, classes, attributes, interfaces, and extension methods in the `EricksonLopez.Mediator` ecosystem.

## 1. Core Abstractions (`EricksonLopez.Mediator`)

### `ICommand<TResponse>`
Defines a command message encapsulating a request to mutate system state in a CQRS architecture.

```csharp
namespace EricksonLopez.Mediator;

public interface ICommand<TResponse>
{
}
```
- **Type Parameters**:
  - `TResponse`: The type of the response produced by executing the command.
- **Remarks**:
  - Commands strictly represent write operations / state mutations.
  - Every `ICommand<TResponse>` must have exactly one corresponding `ICommandHandler<TCommand, TResponse>`.
  - Missing handlers or duplicate handlers are detected at compile-time by the Roslyn Source Generator (`ELM001`, `ELM003`).

---

### `ICommandHandler<in TCommand, TResponse>`
Defines the handler responsible for executing a specific command.

```csharp
namespace EricksonLopez.Mediator;

public interface ICommandHandler<in TCommand, TResponse> 
    where TCommand : ICommand<TResponse>
{
    ValueTask<TResponse> Handle(TCommand command, CancellationToken cancellationToken);
}
```
- **Methods**:
  - `Handle(TCommand command, CancellationToken cancellationToken)`: Executes the command asynchronously.
- **Returns**: `ValueTask<TResponse>` representing the operation. If synchronous or cached, avoids heap allocation.
- **Best Practices**:
  - Keep command handlers focused on a single responsibility.
  - Delegate transaction boundaries and persistence to domain/data layers.

---

### `IQuery<TResponse>`
Defines a query message encapsulating a request to retrieve data without mutating system state.

```csharp
namespace EricksonLopez.Mediator;

public interface IQuery<TResponse>
{
}
```
- **Type Parameters**:
  - `TResponse`: The type of the response generated by executing the query.
- **Remarks**:
  - Queries are read-only and idempotent.
  - Each query is processed by exactly one `IQueryHandler<TQuery, TResponse>`.

## 4. Static Mediator (`StaticMediator`)

Provides high-performance mediation without a dependency injection container.

```csharp
public static class StaticMediator
{
    // Registration
    public static void RegisterCommandHandler<TCommand, TResponse>(ICommandHandler<TCommand, TResponse> handler);
    public static void RegisterQueryHandler<TQuery, TResponse>(IQueryHandler<TQuery, TResponse> handler);
    public static void RegisterNotificationHandler<TNotification>(INotificationHandler<TNotification> handler);

    // Preferred type-safe dispatch (AOT-safe, zero runtime reflection)
    public static ValueTask<TResponse> SendCommand<TCommand, TResponse>(TCommand command, CancellationToken ct = default)
        where TCommand : ICommand<TResponse>;
    public static ValueTask<TResponse> SendQuery<TQuery, TResponse>(TQuery query, CancellationToken ct = default)
        where TQuery : IQuery<TResponse>;
    public static ValueTask Publish<TNotification>(TNotification notification, CancellationToken ct = default)
        where TNotification : INotification;
    public static void Reset();

    // Polymorphic overloads — [Obsolete] (ADR-032). Use SendCommand/SendQuery instead.
    [Obsolete("Use SendCommand<TCommand, TResponse>() for explicit type-safe dispatch.", error: false)]
    public static ValueTask<TResponse> Send<TResponse>(ICommand<TResponse> command, CancellationToken ct = default);

    [Obsolete("Use SendQuery<TQuery, TResponse>() for explicit type-safe dispatch.", error: false)]
    public static ValueTask<TResponse> Send<TResponse>(IQuery<TResponse> query, CancellationToken ct = default);
}
```

## 5. Ecosystem Integrations

### OpenTelemetry (`EricksonLopez.Mediator.OpenTelemetry`)
- `OpenTelemetryBehavior<TRequest, TResponse>`: Pipeline behavior creating distributed trace activities (`ActivitySource`) and recording request metrics.
  - `public OpenTelemetryBehavior()`: Initializes behavior with default `ActivitySource` ("EricksonLopez.Mediator").
  - `public OpenTelemetryBehavior(MediatorOpenTelemetryOptions? options)`: Initializes behavior with customized options.
- `MediatorOpenTelemetryOptions`: Configuration options class for distributed tracing and metric enrichment:
  - `ActivitySourceName` (`string`, default: `"EricksonLopez.Mediator"`): The name of the `ActivitySource`.
  - `EnrichActivity` (`Action<Activity, object>?`): Callback delegate to enrich created `Activity` spans with custom tags from request payloads.
- `MediatorMetrics`: Exposes counters `mediator.requests.total`, `mediator.notifications.total`, `mediator.requests.failures` and histogram `mediator.request.duration`.
- `services.AddMediatorOpenTelemetry(Action<MediatorOpenTelemetryOptions>? configure = null)`: Configures and registers tracing and metrics in dependency injection.

### Polly Resilience (`EricksonLopez.Mediator.Polly`)
- `PollyResilienceBehavior<TRequest, TResponse>`: Executes pipeline continuation inside a Polly v8 `ResiliencePipeline`.
- `[UseResiliencePipeline("PipelineKey")]`: Selects named resilience pipeline.
- `services.AddMediatorPolly()` & `services.AddMediatorDefaultResiliencePipeline(Action<ResiliencePipelineBuilder>)`.

### Rate Limiting (`EricksonLopez.Mediator.RateLimiting`)
- `RateLimitingBehavior<TRequest, TResponse>`: Throttles requests using `System.Threading.RateLimiting.RateLimiter`.
- `RateLimitExceededException`: Thrown when a request is rejected by the rate limiter. Exposes `RetryAfter` (`TimeSpan?`) — the duration after which the client may retry, if provided by the rate limiter lease.
- `services.AddMediatorRateLimiting()`.

### Result Pattern (`EricksonLopez.Mediator.Result`)
- `IResultFactory<out TResponse>`: Factory interface enabling pipeline behaviors to return typed failures (`Result<T>`) without throwing exceptions.

### Testing Doubles (`EricksonLopez.Mediator.Testing`)
- `FakeMediator`: In-memory test double. See [FakeMediator full API reference](#fakemediator-complete-api) below.
- `DelegateNext<TResponse>` / `DelegateNext`: Struct continuation test double for isolated behavior testing.
- `FakeAssertionException`: Thrown by `ShouldHaveReceived` / `ShouldNotHaveReceived` when assertions fail.

### ASP.NET Core Minimal APIs (`EricksonLopez.Mediator.AspNetCore`)
- `endpoints.MapCommand<TCommand, TResponse>(pattern, httpMethod = "POST")`
- `endpoints.MapQuery<TQuery, TResponse>(pattern)`

### Health Checks (`EricksonLopez.Mediator`)
- `MediatorHealthCheck`: Verifies mediator registration readiness for Kubernetes probes.
- `services.AddMediatorHealthCheck()`.

### Exceptions (`EricksonLopez.Mediator`)
- `MediatorValidationException`: Thrown by attribute-based validation (`[ValidateNotNull]`, `[ValidateNotEmpty]`, `[ValidateRange]`, `[ValidateLength]`, `[ValidateRegex]`) when a constraint is violated. Exposes `Errors` (`IReadOnlyList<ValidationError>`).
- `NotificationHandlerAggregateException`: Thrown by `PublishStrategy.SequentialAggregateExceptions` when one or more notification handlers throw. Wraps all individual handler exceptions.

### ISender.SendCommand<TCommand, TResponse>(TCommand command, CancellationToken cancellationToken)

**Signature**
```csharp
ValueTask<TResponse> SendCommand<TCommand, TResponse>(TCommand command, CancellationToken cancellationToken = default)
    where TCommand : ICommand<TResponse>;
```

**Parameters**

| Parameter | Type | Description |
|---|---|---|
| `command` | `TCommand` | The command instance to dispatch. Must implement `ICommand<TResponse>`. |
| `cancellationToken` | `CancellationToken` | Optional. Token for cooperative cancellation. |

**Returns**  
`ValueTask<TResponse>` — The response produced by the registered command handler.

**Exceptions**

| Exception | When |
|---|---|
| `InvalidOperationException` | No handler registered (StaticMediator); handler not found in DI. |
| `MediatorValidationException` | [ValidateRequest] constraints violated before handler is invoked. |
| `OperationCanceledException` | CancellationToken requested cancellation. |

**Remarks**  
Strongly typed dispatch — no boxing of the command into an interface. Preferred over `Send(ICommand<TResponse>)` when the concrete command type is known at the call site.

**When to use:**  
- When you know the exact TCommand type at the call site.
- When you want to avoid boxing overhead on the ISender.Send(ICommand) overload.

**When NOT to use:**  
- When the command type is dynamically resolved at runtime (use `Send(ICommand<TResponse>)` instead).

**Example (basic)**
```csharp
var result = await mediator.SendCommand<CreateUserCommand, string>(
    new CreateUserCommand("alice", "alice@example.com"),
    CancellationToken.None);
```

**Example (advanced)**
```csharp
using var cts = new CancellationTokenSource(TimeSpan.FromSeconds(30));
try
{
    var result = await mediator.SendCommand<CreateOrderCommand, Result<OrderResponse>>(
        new CreateOrderCommand("SKU-001", 5, "Alice Corp"),
        cts.Token);
    if (result.IsFailure) Console.WriteLine(result.Error.Description);
}
catch (OperationCanceledException)
{
    Console.WriteLine("Request timed out.");
}
```

**Performance**  
SendCommand is monomorphized by the Source Generator. The dispatch is a direct type-switch with zero heap allocation. Combined with a Singleton handler, the entire path is 0 B allocated.

**Common mistakes**
- Calling SendCommand with an open generic type parameter — the generator requires closed, concrete types.
- Not checking CancellationToken inside the handler, causing the token to be ignored.

### ISender.SendQuery<TQuery, TResponse>(TQuery query, CancellationToken cancellationToken)

**Signature**
```csharp
ValueTask<TResponse> SendQuery<TQuery, TResponse>(TQuery query, CancellationToken cancellationToken = default)
    where TQuery : IQuery<TResponse>;
```

**Parameters** — Same pattern as SendCommand.

**Returns** — `ValueTask<TResponse>`: the query response. Must be a pure read — no side effects.

**When to use:** Pure read operations, reports, projections, lookups.

**When NOT to use:** Any operation that mutates state. Use ICommand for writes.

**Example (basic)**
```csharp
var user = await mediator.SendQuery<GetUserByIdQuery, UserDto?>(
    new GetUserByIdQuery(userId), CancellationToken.None);
```

### IPublisher.Publish<TNotification>(TNotification notification, CancellationToken cancellationToken)

**Signature**
```csharp
ValueTask Publish<TNotification>(TNotification notification, CancellationToken cancellationToken = default)
    where TNotification : INotification;
```

**Returns** — `ValueTask`: completes when all handlers finish (or AggregateException if SequentialAggregateExceptions strategy is used).

**Exceptions**

| Exception | When |
|---|---|
| `NotificationHandlerAggregateException` | Any handler throws under `PublishStrategy.SequentialAggregateExceptions`. |
| `AggregateException` | Any handler throws under `PublishStrategy.Parallel`. |

**When to use:** Domain events, integration events, audit triggers, cache invalidation, email notifications.

**When NOT to use:** Operations that require a response from the handler — use ISender instead.

**Example (basic)**
```csharp
await publisher.Publish(new OrderPlacedEvent(orderId, total), CancellationToken.None);
```

**Example (advanced — with exception handling)**
```csharp
try
{
    await publisher.Publish(new CriticalAlertEvent("DB overload"), CancellationToken.None);
}
catch (NotificationHandlerAggregateException aggEx)
{
    foreach (var ex in aggEx.HandlerExceptions)
        logger.LogError(ex, "Subscriber failed.");
}
```

**Signature**
```csharp
IAsyncEnumerable<TResponse> CreateStream<TResponse>(IStreamRequest<TResponse> request, CancellationToken cancellationToken = default);
```

**Returns** — `IAsyncEnumerable<TResponse>`: a lazy async stream consumed with `await foreach`.

**When to use:** Large dataset projections, real-time event feeds, chunked processing where buffering everything in memory is unacceptable.

**When NOT to use:** Small, finite result sets — use IQuery<IReadOnlyList<T>> instead.

**Example**
```csharp
await foreach (var item in mediator.CreateStream(new AuditLogStreamRequest(), CancellationToken.None))
{
    await ProcessItemAsync(item);
}
```

### MediatorHealthCheck.CheckHealthAsync(HealthCheckContext context, CancellationToken cancellationToken)

**Signature**
```csharp
Task<HealthCheckResult> CheckHealthAsync(HealthCheckContext context, CancellationToken cancellationToken = default);
```

**Returns**
- `Healthy` — when `ISender` is registered and resolvable in the DI container.
- The failure status (default: `Degraded`) — when `ISender` is `null` (not registered). The exact status is configurable via `HealthCheckRegistration.FailureStatus` when registering the health check (e.g., `services.AddMediatorHealthCheck()` defaults to `Degraded`; you can override it to `Unhealthy` via `AddHealthChecks().Add(new HealthCheckRegistration(..., failureStatus: HealthStatus.Unhealthy, ...)`).

**Registration**
```csharp
services.AddMediatorHealthCheck();
app.MapHealthChecks("/healthz");
```

**When to use:** Kubernetes liveness/readiness probes to verify the mediator dispatch engine is ready.
