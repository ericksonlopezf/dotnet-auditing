# Project Governance

## 1. Overview
The `EricksonLopez.Mediator` project is an open-source software library authored and maintained by Erickson Lopez.

## 2. Decision-Making Process
All architectural and design decisions follow formal Architectural Decision Records (ADRs) documented in `docs/adr/`.

## 3. Contribution Workflow
1. Fork and create a feature branch.
2. Implement feature adhering to zero-allocation and Native AOT standards.
3. Verify 100% compliance with `./scripts/verify-compliance.ps1`.
4. Ensure all unit and mutation tests pass.
